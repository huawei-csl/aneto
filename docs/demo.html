Try the model

The demo runs the calibrations of the paper in your browser. They cover five CPUs and three simulator configurations, measured for the paper. Aneto reads a single run of each workload and never sees the sweep of that workload. Compare its prediction with the ground-truth fit of the sweep, then try other target memories.

Try your own counters

Enter the counters of a single run on the selected machine. Aneto, calibrated on all workloads of that machine, places the run in panel 1 and predicts its CPI on the target memory.

If you did not measure the memory latency, keep the unloaded latency of the machine. The prediction holds only for runs on the calibrated machine, under the same run conditions (machines).
